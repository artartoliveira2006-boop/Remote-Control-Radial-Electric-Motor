# Modelos para fabricação 3D

Esta pasta contém três malhas STL binárias fornecidas a partir do projeto mecânico:

| Arquivo | Função informada | Triângulos | Dimensões da malha (X x Y x Z) |
| --- | --- | ---: | --- |
| `bobina.stl` | Corpo/suporte da bobina | 1.804 | 40,00 x 39,98 x 80,00 |
| `encapsulamento-esquerdo.stl` | Metade esquerda do encapsulamento | 766 | 29,00 x 64,27 x 80,00 |
| `encapsulamento-direito.stl` | Metade direita do encapsulamento | 766 | 24,00 x 64,27 x 80,00 |

As dimensões acima foram calculadas a partir dos limites geométricos dos arquivos. O formato STL não armazena a unidade de medida; confirme no software de modelagem ou fatiamento se os valores devem ser interpretados em milímetros antes de fabricar.

## Arquivos que ainda podem complementar o projeto

- modelo paramétrico original ou conjunto em `.step`/`.stp`;
- imagem renderizada ou captura da montagem completa;
- nome e versão do software usado na modelagem;
- orientação, preenchimento, material e demais parâmetros de impressão;
- tolerâncias e método de união das duas metades do encapsulamento.
